# Contains Duplicate

**Difficulty:** Easy
**Source:** https://leetcode.doocs.org/en/lc/217/ (LeetCode 217; NeetCode/LeetCode pages unavailable)

## Problem

Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

## Examples

1. Input: `nums = [1,2,3,1]`
   Output: `true`
   Explanation: the value 1 appears at indices 0 and 3.
2. Input: `nums = [1,2,3,4]`
   Output: `false`
   Explanation: all elements are distinct.
3. Input: `nums = [1,1,1,3,3,4,3,2,4,2]`
   Output: `true`

## Constraints

- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
